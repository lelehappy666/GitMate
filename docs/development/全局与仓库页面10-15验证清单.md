# 全局与仓库页面 10–15 验证清单

## 验证范围

本清单覆盖页面 10–15 的真实依赖装配、只读数据边界、异常状态、默认窗口与
最小窗口。默认窗口为 1180×760，最小窗口为 1040×680；尺寸均包含左侧栏。

## 通用检查

- [ ] 当前账户使用 GitHub 用户头像，不显示姓名首字母占位遮挡头像。
- [ ] 白色主色调、深色正文、高对比焦点色与前序页面一致。
- [ ] 左侧栏固定，切换当前仓库后页面 12–15 始终指向同一仓库。
- [ ] 主窗口不出现纵向滚动；列表、README、差异和提交画布在内容区内部滚动。
- [ ] 1180×760 下标题、工具栏、底部状态完整可见。
- [ ] 1040×680 下侧栏与详情区不横向溢出，按钮和状态条不被遮挡。
- [ ] 切换账户后旧页面加载任务取消，本地仓库目录不被删除。
- [ ] 钥匙串缺少令牌或读取失败时，只显示稳定的“需要重新授权”状态。
- [ ] 页面不显示访问令牌、请求鉴权头或底层钥匙串错误。

## 页面 10：全局工作台

运行：

```bash
swift run GitMate --preview-page 10
swift run GitMate --preview-page 10 --preview-state offline
swift run GitMate --preview-page 10 --preview-state error
```

- [ ] 今日焦点是首要视觉中心，警告与成功状态文字对比清晰。
- [ ] 仓库健康、本地改动、开放 Issue、PR 和 Actions 失败数量可读。
- [ ] 离线时保留本地仓库状态，并显示稳定离线提示。
- [ ] 点击“全部仓库”进入页面 11。

## 页面 11：仓库封面墙

运行：

```bash
swift run GitMate --preview-page 11
swift run GitMate --preview-page 11 --preview-state offline
swift run GitMate --preview-page 11 --preview-state error
```

- [ ] 固定展示 3 个仓库，包含私有仓库与一个“不同步”仓库。
- [x] 默认显示本地仓库，云端仓库使用独立入口且不计入本地健康度。
- [x] 云端仓库每页最多加载 30 个，并排除已经存在的本地仓库。
- [x] README 有有效封面候选；无候选或下载失败时卡片比例保持不变。
- [x] 封面只调度当前窗口和下一行，最多并发 3 路且缓存可复用。
- [x] 刷新云端仓库会标记封面重新检查，失败时继续保留旧缓存。
- [x] 搜索、可见性、语言、同步状态和排序控件可用。
- [x] 云端语言菜单使用仓库列表返回的主要语言，不再始终为空。
- [x] 默认窗口下搜索、筛选、排序和结果数保持单行；空间不足时自动回退双行。
- [x] 卡片显示仓库名、语言、大小和同步模式。
- [x] 已加载封面不会改变 2:3 卡片边界，也不会伸入侧栏。
- [x] 内容背景铺满 1040×680 与 1180×760 窗口剩余高度。
- [ ] 点击仓库海报进入对应页面 12。
- [x] 云端仓库可单独选择手动同步或自动同步，不触发其他仓库下载。
- [x] “下载”位于卡片固定底栏右侧，不覆盖“尚未同步”状态。
- [x] 本地页标题和空状态均提供“添加本地仓库”，取消选择不改变页面。
- [x] 添加流程只运行只读 Git 命令，并拒绝无 origin、分离 HEAD 或主机不匹配。
- [x] 同一远端重复添加会更新原始路径，重启后仍可恢复登记。
- [x] 云端分页按仓库全名排除已导入仓库，并回填真实编号、可见性、头像和语言。
- [x] 导入成功只增量更新仓库分组，不在界面线程重复统计全部仓库大小。
- [x] 持久化记录会移除远端 URL 的用户名、密码、查询参数和片段。

## 自动化命令

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
CLANG_MODULE_CACHE_PATH=/private/tmp/gitmate-clang-module-cache \
SWIFT_MODULECACHE_PATH=/private/tmp/gitmate-swift-module-cache \
swift run --disable-sandbox GitMateCoreTestsRunner

DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
CLANG_MODULE_CACHE_PATH=/private/tmp/gitmate-clang-module-cache \
SWIFT_MODULECACHE_PATH=/private/tmp/gitmate-swift-module-cache \
swift build --disable-sandbox

git diff --check
```

另需搜索源码与文档中的待办占位标记、令牌查询参数和明文鉴权头。验收时要求
全部测试零失败、应用编译成功、没有占位或明文敏感信息，并且
`git diff --check` 无输出。

本轮新增验证覆盖 233 项自动化测试；已通过 macOS 界面检查确认本地添加按钮、
`NSOpenPanel` 说明、默认窗口工具栏和云端卡片固定底栏没有重叠。
