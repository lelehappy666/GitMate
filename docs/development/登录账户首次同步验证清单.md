# 登录、账户与首次同步验证清单

## 本阶段范围

本阶段只开发第 01–09 页：

1. 登录入口
2. GitHub.com 设备授权
3. GitHub Enterprise 连接
4. 账户与权限确认
5. 仓库首次同步设置
6. 首次同步进度
7. 仓库同步错误
8. 网络中断与恢复
9. 授权失效与重新授权

未开发综合工作台、仓库详情、提交图、议题、拉取请求等第 10 页以后的功能。

## 自动化验证

- 页面 01–09 路由与状态转换
- GitHub Device Flow 请求、轮询、降速、拒绝与令牌解析
- GitHub 用户头像、权限与仓库字段解析
- GitHub Enterprise 地址标准化、HTTPS 限制与令牌失效映射
- 凭据保存、覆盖、读取、删除与账户隔离
- 不同步、手动同步、自动同步偏好
- clone、fetch、实时文件事件、长条进度与单仓库失败继续
- 网络中断与授权失效错误映射
- ViewModel 登录、仓库加载、同步和异常页面编排
- 私有仓库令牌不进入 Git 命令参数，通过临时 Git 环境传递

验证命令：

```bash
CLANG_MODULE_CACHE_PATH=.build/clang-module-cache \
SWIFT_MODULECACHE_PATH=.build/swift-module-cache \
swift run --disable-sandbox GitMateCoreTestsRunner

CLANG_MODULE_CACHE_PATH=.build/clang-module-cache \
SWIFT_MODULECACHE_PATH=.build/swift-module-cache \
swift build --disable-sandbox
```

## 视觉与交互检查

- 主色调为白色，正文使用高对比深色
- 登录页只有 GitHub 与 GitHub Enterprise 登录选项，软件效果图叠在背景
- 应用最小尺寸为 1040 × 680，默认尺寸为 1180 × 760
- 内容区适应固定软件高度，长列表只在面板内部滚动
- 用户位置使用真实 GitHub 头像
- 仓库列表显示大小、可见性、默认分支与三种同步方式
- 同步进度使用横向进度条，不使用环形进度
- 同步页实时显示当前仓库和当前文件
- 第 07–09 页保留同步现场，并提供重试或重新授权入口
