## 真实仓库入口

只对用户明确指定的仓库根目录执行：

```bash
swift run GitMate --local-repository /绝对路径/到/仓库
```

确认：

- 非 Git 目录、相对路径和重复参数被拒绝。
- 顶部与侧边栏显示“真实仓库”。
- 暂存、提交和 Fetch 可直接执行。
- Pop、删除、历史改写、二进制整文件选择、删除远程、Pull 和 Push 均显示确认。
- 强制推送命令只有精确 `force-with-lease`，没有裸 `--force`。

## 中断与恢复

- Fetch 与 Push 可取消，Git 子进程终止后仓库保持可用。
- Pull 仅允许在 Fetch 阶段取消；进入本地整合后等待 Git 到达安全状态。
- Merge、Rebase 和 Cherry-pick 冲突可在重新启动后重新检测。
- 全部冲突解决后“继续”可用，“中止”恢复操作前状态。
- Stash Apply 冲突时原 Stash 仍存在。
- Hook 或签名失败时暂存区和提交说明保持不变。

## 安全检查

- Token 只进入子进程环境，不进入参数、界面、Journal 或日志。
- HTTPS URL 展示前移除用户信息，认证头全部脱敏。
- SSH 操作不读取 GitHub Token，也不覆盖系统 SSH Agent。
- 测试写操作只发生在临时仓库及其本地 Bare Remote。
- 生产远程策略拒绝本地路径和不支持的协议。
