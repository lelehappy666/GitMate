# 分支、标签与议题验证清单

## 自动验证

在项目根目录运行：

```bash
CLANG_MODULE_CACHE_PATH=.build/clang-module-cache \
SWIFT_MODULECACHE_PATH=.build/swift-module-cache \
swift run --disable-sandbox GitMateCoreTestsRunner
```

预期结果：

- 完成 82 个测试。
- 失败 0 个。
- 覆盖路由、领域模型、REST 请求、本地 Git 安全参数、草稿持久化、危险操作确认、标签合并和里程碑画布布局。

编译原生应用：

```bash
CLANG_MODULE_CACHE_PATH=.build/clang-module-cache \
SWIFT_MODULECACHE_PATH=.build/swift-module-cache \
swift build --disable-sandbox
```

预期结果：`Build complete!`

检查补丁格式：

```bash
git diff --check
```

预期结果：无输出，退出状态为 0。

## 页面预览

开发预览不会访问真实 GitHub 或修改真实仓库：

```bash
swift run GitMate --preview-page 16
swift run GitMate --preview-page 17
swift run GitMate --preview-page 18
swift run GitMate --preview-page 19
swift run GitMate --preview-page 20
swift run GitMate --preview-page 21
swift run GitMate --preview-page 22
swift run GitMate --preview-page 23
```

## 第 16–18 页

- 第 16 页同时显示本地与远端分支。
- 仅本地、仅远端、已同步、领先、落后和分叉状态可区分。
- 脏工作区会阻止签出、合并等危险操作。
- 删除本地或远端分支前显示影响范围确认。
- 第 17 页区分轻量标签和附注标签。
- 标签显示本地、远端和同步状态，并可进入 Release。
- 第 18 页可创建和编辑仓库 Ruleset。
- 组织继承 Ruleset 显示来源并保持只读。

## 第 19–21 页

- 议题搜索、状态、标签、排序和方向筛选有效。
- 保存的议题视图按账户和仓库隔离。
- 点击议题进入详情页，真实用户位置使用 GitHub 头像。
- 正文和评论按 Markdown 渲染。
- 发表评论、关闭、重新打开、锁定和解锁调用真实接口。
- 新建议题支持模板、编写与预览切换。
- 发布失败时保留本地草稿，重新打开页面可以恢复。

## 第 22 页

- 主区域为无限画布，没有固定详情侧栏。
- 鼠标拖动可以平移画布，触控板手势可以缩放。
- 自动聚焦按钮可以重新完整显示全部节点。
- 节点按截止日期排列，未排期里程碑显示在最后。
- 点击节点后弹出详情，关闭弹窗后仍保持画布位置。
- 删除里程碑前显示受影响议题数量。

## 第 23 页

- 标签卡片显示颜色、说明、进行中议题和已关闭议题数量。
- 标签颜色使用六位十六进制并保持文字可读。
- 创建、编辑和删除调用真实 GitHub 标签接口。
- 合并时来源和目标不能相同。
- 合并失败会保留已完成与失败议题编号，重试时跳过已完成项。
- 全部议题更新成功后才删除来源标签。

## 窗口与视觉

- 默认窗口为 1180 × 760，最小窗口为 1040 × 680。
- 主窗口没有网页式纵向滚动。
- 侧边栏、列表、详情、编辑器和画布在各自区域内滚动。
- 全部页面使用白色主调、浅灰层级和高对比文字。
- 不显示收件箱和项目模块。
