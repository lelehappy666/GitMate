# 分支、标签与议题验证清单

## 实验功能开关

- 打开工作区，预期默认不显示“分支、标签与议题”入口。
- 在侧边栏底部点击“设置”，进入“实验功能”后开启开关，预期入口立即在原位置显示。
- 进入仓库管理工作区后点击“仓库设置”关闭开关，预期立即返回全局工作区，且不再显示入口。
- 重启应用，预期实验功能开关仍保持关闭状态。
- 打开提交图，检查分支列表、分支连线和筛选，预期均正常且不受实验功能开关影响。

## 自动验证

在项目根目录运行：

```bash
CLANG_MODULE_CACHE_PATH=.build/clang-module-cache \
SWIFT_MODULECACHE_PATH=.build/swift-module-cache \
swift run --disable-sandbox GitMateCoreTestsRunner
```

预期结果：

- 完成 570 个测试。
- 失败 0 个。
- 覆盖路由、领域模型、REST 请求与路径编码、本地 Git 安全参数、异步防串页、草稿持久化、危险操作确认、标签合并和里程碑画布布局。

编译原生应用：

```bash
CLANG_MODULE_CACHE_PATH=.build/clang-module-cache \
SWIFT_MODULECACHE_PATH=.build/swift-module-cache \
swift build --disable-sandbox
```

预期结果：`Build complete!`

检查补丁格式：

```bash
git diff --check
```

预期结果：无输出，退出状态为 0。

## 仓库总览与介绍入口

- 从第 16–23 页侧边栏点击“总览”，进入同一仓库的真实总览页面。
- “总览”和“介绍”使用高对比文字，不再呈灰色禁用状态。
- 总览中的“查看完整 README”继续保留仓库侧边栏，并高亮“介绍”。
- 总览中的文件与提交、提交图入口进入既有第 14、15 页。
- 第 12、13 页预览只使用本地假数据，不读取钥匙串或访问真实 GitHub。

## 第 16–18 页

- 第 16 页同时显示本地与远端分支。
- 仅本地、仅远端、已同步、领先、落后和分叉状态可区分。
- 脏工作区会阻止签出、合并等危险操作。
- 删除本地或远端分支前显示影响范围确认。
- 删除本地分支前检查工作区是否干净，脏工作区会阻止删除。
- 第 17 页区分轻量标签和附注标签。
- 标签同时读取本地与远端引用，显示同步状态，并可进入 Release。
- 以 `-` 开头的标签名不会被 Git 误识别为命令参数。
- 第 18 页可创建和编辑仓库 Ruleset。
- 组织继承 Ruleset 显示来源并保持只读。
- 编辑已存在的 Ruleset 时保留界面暂未呈现的规则和绕过主体。
- 降低规则强度或扩大绕过范围时显示影响范围确认。

## 第 19–21 页

- 议题搜索、状态、标签、排序和方向筛选有效。
- 保存的议题视图按账户和仓库隔离。
- 点击议题进入详情页，真实用户位置使用 GitHub 头像。
- 正文和评论按 Markdown 渲染。
- 发表评论失败时保留编辑内容，评论编辑失败时同样保留原文。
- 议题标题、正文、负责人、标签和里程碑可编辑。
- 发表评论、编辑评论、关闭、重新打开、锁定和解锁调用真实接口。
- 新建议题支持模板、编写与预览切换。
- 选择模板时不会覆盖已有正文，草稿采用防抖保存。
- 发布失败时保留本地草稿，重新打开页面可以恢复。

## 第 22 页

- 主区域为无限画布，没有固定详情侧栏。
- 鼠标拖动可以平移画布，触控板手势可以缩放。
- 自动聚焦按钮可以重新完整显示全部节点。
- 节点按截止日期排列，未排期里程碑显示在最后。
- 不同截止日期按真实时间间隔映射，并保留最小可读间距。
- 点击节点后弹出详情，关闭弹窗后仍保持画布位置。
- 新建仅包含标题的里程碑时，创建请求不发送空描述和空截止日期。
- 新建带描述和截止日期的里程碑时，日期使用 UTC ISO 8601 格式。
- 编辑里程碑后清空描述或取消截止日期时，更新请求显式发送 `null`。
- 保存期间取消和保存按钮不可重复触发，并显示“正在保存…”。
- GitHub 返回 422 时编辑窗口保持打开，标题、描述、状态和日期全部保留。
- 422 行内错误显示 GitHub 返回的资源、字段、错误码和详情消息。
- GitHub 返回 403 时提示需要 Issues 或 Pull Requests 写权限。
- 失败后修正输入再次保存，只有成功时才关闭编辑窗口并更新画布节点。
- 删除里程碑前显示受影响议题数量。

## 第 23 页

- 标签卡片显示颜色、说明、进行中议题和已关闭议题数量。
- 使用量来自仓库全部非拉取请求议题，而不是预览占位值。
- 标签颜色使用六位十六进制并保持文字可读。
- 创建、编辑和删除调用真实 GitHub 标签接口。
- 合并时来源和目标不能相同。
- 合并失败会保留已完成与失败议题编号，重试时跳过已完成项。
- 全部议题更新成功后才删除来源标签。

## 窗口与视觉

- 默认窗口固定为 1180 × 760。
- 主窗口没有网页式纵向滚动。
- 侧边栏、列表、详情、编辑器和画布在各自区域内滚动。
- 全部页面使用白色主调、浅灰层级和高对比文字。
- 不显示收件箱和项目模块。
