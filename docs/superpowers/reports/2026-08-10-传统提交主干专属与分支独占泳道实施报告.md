# 传统提交主干专属与分支独占泳道实施报告

## 实施结果

- `main` 始终使用最左侧 0 号泳道。仓库不存在本地或远程 `main` 时，0 号泳道保持空白，其他分支从 1 号泳道开始。
- 每个逻辑分支获得独立泳道，不再根据行内占用情况借用其他分支的泳道。
- 共享提交节点只绘制一次，分叉、Merge 和共享祖先通过跨泳道连线表达关系。
- 本地 `main` 与 `origin/main` 在提交链线性相关时合并为同一逻辑分支；真实分叉时拆分为相邻泳道。
- 远程已知提交使用实线，本地未推送提交使用虚线；分支、远程引用与标签在提交行徽标中保留。
- 移除了容易被误解为提交线的水平引用线和方形端点。
- 分支与区段投影在快照刷新时于后台一次派生，绘制阶段只使用 O(1) 哈希查询，不再每帧重算分支归属。
