# 大量提交图布局验证报告

## 验证范围

本轮验证覆盖画布主干/分支束、传统布局四到八条上下文泳道、本地与远程分支识别、Group/版本区域/手动位置保护、五万提交与三百分支性能，以及 macOS Release 应用包。

## 功能结果

- 画布保持最早提交在上、最新提交在下；主干居中，其他分支按稳定身份向左右生长。
- 远景将连续普通提交投影为可点击展开的分支束，分叉、Merge、HEAD、refs、Tag、Group、区域和浅克隆边界仍保留为独立锚点。
- 传统布局根据窗口宽度固定显示四到八个上下文槽，不再因大量分支无限变宽。
- 本地分支使用实线和实心标识，远程分支使用虚线和描边标识；隐藏分支分别统计本地与远程数量。
- 分支搜索浮层可搜索并临时显示任意本地/远程分支，也可固定或取消固定。
- 工作区未提交变更保持为独立本地状态，与 Git 提交历史明确区分。

## 退化策略

- 无 refs 时使用 HEAD/主干回退。
- Detached HEAD 作为独立上下文显示。
- 分支束索引为空时保留普通节点。
- 传统分支投影为空时至少保留主干回退。
- 浅克隆缺失父提交继续显示明确的边界端点。
- 刷新或缓存失败时继续显示上一次正确拓扑，并标记陈旧状态。
