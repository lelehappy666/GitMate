# 传统提交头像与横向视口修复验证报告

## 修复范围

- 传统提交视图的工作区变更栏与分支栏保持固定，提交 Canvas、头像和无障碍层在下方裁剪视口内统一横向移动。
- 头像层只创建当前可见行，避免预加载头像穿透到固定头部。
- 触控板横向滚动和鼠标拖动均可移动完整提交内容；拖动超过 4 点后不会误触提交详情。
- GitHub noreply 邮件继续解析真实头像；当前账户登录名或显示名匹配时复用账户头像；其他作者使用稳定颜色的首字母头像。
- 未增加 GitHub API 请求，远程头像继续复用现有内存缓存。
