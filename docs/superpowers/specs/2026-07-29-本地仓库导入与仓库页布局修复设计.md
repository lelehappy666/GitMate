# GitMate 本地仓库导入与仓库页布局修复设计

## 1. 目标

本次改动解决仓库页的四个问题：

- 本地仓库页可以添加 Mac 上已有的 GitHub 仓库。
- 云端仓库卡片底部的下载操作不再遮挡状态文字。
- 云端仓库工具栏减少无效留白，并在常用窗口高度内保持清晰层级。
- 云端仓库使用 GitHub 返回的真实语言字段提供语言筛选。

## 2. 本地仓库导入边界

添加仓库采用“原地登记”方式：

- 用户通过 macOS 文件夹选择器选择一个仓库目录。
- GitMate 不移动、不复制、不创建符号链接，也不修改仓库内容。
- 目录必须是有效的 Git 工作树，并且存在可识别的 GitHub `origin`。
- GitMate 读取仓库根目录、`origin`、当前分支和目录大小，生成本地仓库记录。
- 导入结果按账户持久保存，重新启动后仍出现在本地仓库、侧栏和工作台中。
- 同一路径或同一仓库重复添加时合并为一条记录。
- 原目录被移动或删除后，仓库显示为不可用，但不会自动删除登记记录。

本阶段只登记 GitHub.com 或当前账户 GitHub Enterprise 主机上的仓库。其他 Git
托管服务显示明确错误，不作为 GitHub 仓库导入。

## 3. 数据结构与组件

### 3.1 本地仓库导入器

新增独立的导入器，输入用户选择的目录与当前账户，输出：

- `Repository`：仓库编号、名称、所有者、默认分支和远程地址。
- 本地目录 URL。
- 可用性与本地大小。

导入器只执行以下只读 Git 命令：

- `rev-parse --show-toplevel`
- `remote get-url origin`
- `symbolic-ref --short HEAD`

仓库编号由规范化远程地址稳定派生，避免重新启动后编号变化，并使同一远程仓库
在不同本地路径下仍合并为一条登记记录；重新添加时使用最新选择的路径。

### 3.2 持久登记存储

新增按账户保存的本地仓库登记存储。每条记录包含仓库模型和规范化本地路径。
存储不保存访问令牌，也不会把远程地址中的用户名、密码或查询参数写入磁盘。

### 3.3 本地目录解析

`LocalRepositoryCatalog` 优先使用已经登记的本地路径；没有登记路径的仓库继续
使用 GitMate 默认同步目录。工作台、README、文件、提交和提交图因此共享同一
真实本地路径。

## 4. 界面设计

### 4.1 本地仓库页

- 标题右侧增加蓝色“添加本地仓库”按钮。
- 空状态增加相同操作按钮，用户不需要先寻找工具栏。
- 导入成功后立即刷新本地仓库墙、侧栏和工作台数据。
- 无效目录、非 Git 仓库、缺少 GitHub origin 或读取失败时显示一条可关闭的中文
  错误提示，不离开当前页面。

### 4.2 云端仓库卡片

下载操作从卡片右下角浮层改为独立底部操作区：

- 左侧显示“尚未同步”状态。
- 右侧使用紧凑的下载菜单，提供“手动同步”和“自动同步”。
- 操作区拥有固定高度，仓库名称、状态和按钮不重叠。

### 4.3 云端工具栏

采用紧凑两行结构：

- 第一行：标题与说明在左侧，刷新按钮和仓库数量在右侧。
- 第二行：搜索框占主要宽度；可见性、语言、排序和结果数量在同一工具行。
- 本地页额外显示同步状态筛选。
- 控件在 1040×680 和 1180×760 窗口中不换成分散的纵向列。

## 5. 云端语言数据

GitHub `/user/repos` 返回的 `language` 字段写入 `Repository.primaryLanguage`。
该字段为可选值，兼容旧缓存。云端海报直接使用该字段生成语言标签和筛选列表；
GitHub 返回空语言时显示“未知语言”，但不把“未知语言”作为可选筛选项。

## 6. 错误与安全处理

- 文件夹选择器取消操作不显示错误，也不改变仓库列表。
- Git 命令参数使用独立数组传递，不拼接 shell 字符串。
- 远程地址只接受 HTTPS、SSH URL 或 GitHub 常见的 SCP 风格 SSH 地址。
- 持久化前移除远程地址中的凭据、查询参数和片段。
- 导入过程不执行 fetch、pull、checkout、config 写入或其他仓库写操作。
- 文件夹权限不足时显示可读错误，并保留现有仓库数据。

## 7. 验证

自动化测试至少覆盖：

- 有效 HTTPS 与 SSH GitHub origin 的解析。
- 非 Git 目录、缺少 origin 和非 GitHub 主机被拒绝。
- 同账户导入记录持久保存、去重和恢复。
- 登记路径优先于默认同步目录。
- GitHub API 正确解析语言并在云端海报中生成语言列表。
- 云端下载只同步目标仓库。
- 所有既有测试继续通过。

界面验收覆盖：

- 本地仓库空状态可以直接添加仓库。
- 下载按钮与状态文字无重叠。
- 云端工具栏在默认和最小窗口中不溢出。
- 云端语言菜单包含真实语言。
- 应用重新打包并通过本地签名验证。
