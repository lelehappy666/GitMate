# 分支、标签与议题功能设计

## 目标

在已完成的 GitMate 原生 macOS 应用中开发第 16–23 页，提供真实可用的分支、标签、规则集、议题、评论、里程碑和议题标签管理能力。

本阶段不开发第 24 页之后的拉取请求、Actions、Releases 等模块，但允许从当前页面跳转到未来入口或 GitHub 网页。

## 全局约束

- 平台最低版本为 macOS 14。
- 使用 Swift 6、SwiftUI、Observation、Foundation、Security 与系统 `/usr/bin/git`。
- 不新增第三方运行时依赖。
- 页面采用白色主色、高对比深色文字和蓝色主操作色。
- 默认窗口为 1180 × 760，最小窗口为 1040 × 680。
- 左侧仓库导航和顶部账户、仓库上下文保持固定，长列表只在内容面板内部滚动。
- GitHub 用户位置使用真实头像；仓库位置使用仓库图标。
- 所有界面文案、开发文档和 Git 提交使用中文。
- 当前产品主要供单人使用，不引入收件箱或团队任务分派中心。
- 所有危险操作必须显示精确目标和影响范围，并要求二次确认。

## 已确认页面

### 第 16 页：分支管理

- 在同一列表合并显示本地分支、远程分支和跟踪关系。
- 显示默认分支、当前分支、领先、落后、仅本地、仅远端、已同步和保护状态。
- 搜索分支名称或最后提交，并支持隐藏或显示已合并分支。
- 选中分支后显示与默认分支的关系、工作区状态、起点提交、创建者、最近推送和保护规则。
- 支持真实执行刷新、创建本地分支、签出、设置上游、推送、合并和删除。
- 工作区存在未提交变更时，签出和删除等操作必须被安全拦截，并提供“先提交”“暂存后继续”或取消。
- 删除本地分支和远程分支分别确认，远程删除必须明确显示远端名称。

### 第 17 页：标签管理

- 合并本地与远端同名标签并去重，显示仅本地、已同步和未推送状态。
- 显示轻量标签、附注标签、目标提交、创建者、签名验证和关联 Release。
- 支持真实执行刷新、创建轻量或附注标签、推送单个标签、同步远端标签和删除。
- 删除本地与远端标签分开确认；远端删除显示受影响的完整标签名。
- Release 详情在本阶段只显示摘要并提供“在 GitHub 打开”，不开发第 51–53 页。

### 第 18 页：分支规则与 GitHub Ruleset

- 显示仓库 Ruleset 与组织继承规则，区分启用、禁用和评估模式。
- 显示目标引用、包含与排除模式、优先级、当前匹配数量和来源。
- 详情展示拉取请求合并要求、代码所有者审核、必需状态检查、强推、删除和绕过角色。
- 支持仓库 Ruleset 的创建、编辑、启用、禁用和删除。
- 组织继承 Ruleset 为只读，提供来源说明和 GitHub 网页入口。
- 禁用或删除规则集必须显示当前匹配分支和可能放开的保护能力。

### 第 19 页：议题总览

- 显示打开和已关闭议题，支持搜索、状态、作者、负责人、标签、里程碑和排序筛选。
- 搜索框支持 GitHub Issue 查询语法；常用条件以可移除筛选胶囊呈现。
- 每行显示状态、编号、标题、标签、创建者头像、负责人头像、里程碑、评论数和更新时间。
- 支持分页加载和手动刷新。
- 右侧显示分配给我、等待回复、高优先级、未分配、保存视图、当前里程碑和常用标签。
- 保存视图只保存在本机账户会话中，不创建 GitHub 资源。

### 第 20 页：议题详情

- 主面板显示 Markdown 正文、评论和状态事件组成的时间线。
- 评论编辑器固定在主面板底部，时间线独立滚动。
- 支持发表评论、编辑正文、编辑自己的评论、关闭、重新打开、锁定和解锁讨论。
- 右侧集中编辑负责人、标签、里程碑和通知状态，并显示关联分支与拉取请求摘要。
- GitHub REST API 不支持删除议题，因此不提供伪删除按钮；管理区显示“GitHub 不支持删除议题”说明。
- 转移议题和转换为讨论不在本阶段 REST 范围内，提供“在 GitHub 打开”。

### 第 21 页：新建议题

- 支持 Bug 报告、功能建议和空白议题模板切换。
- 支持标题、GitHub Markdown 正文、预览、任务清单、用户提及和议题引用。
- 右侧设置负责人、标签和里程碑，并显示最终发布仓库与账户身份。
- 草稿按账户和仓库保存在本机，退出页面后可以恢复。
- 发布前检查必填字段、标题长度、正文、相似打开议题和 GitHub 校验错误。
- GitHub REST API 没有通用附件上传接口，本阶段不伪造附件上传；附件入口解释限制并可跳转 GitHub 网页编辑器。

### 第 22 页：里程碑可视化管理

- 使用横向无限画布表达月份、今天标线、里程碑跨度、完成节点和未完成节点。
- 支持拖动画布、缩放、适配全部和搜索里程碑。
- 点击里程碑节点后弹出详情，不固定占用画布宽度。
- 弹出详情显示状态、截止日期、打开与关闭数量、完成进度、预计完成时间和仍打开议题。
- 支持真实创建、编辑、关闭、重新打开和删除里程碑。
- 删除前显示关联议题数量；确认后 GitHub 会移除这些议题的里程碑关联，但不会删除议题。

### 第 23 页：议题标签管理

- 标签卡片显示颜色、名称、描述、使用次数和 GitHub 默认标签状态。
- 支持搜索、新建、编辑、删除和恢复 GitHub 默认标签。
- 右侧显示颜色分布、热门标签、未使用标签、疑似重复、缺少描述和覆盖率。
- 标签合并按真实可恢复流程执行：先把来源标签的议题批量添加目标标签，再移除来源标签，最后删除来源标签。
- 合并和删除前显示受影响议题数量；中途失败时保留进度和失败议题列表，允许重试。

## 架构

### 领域模型

`GitMateCore` 新增独立模型：

- `GitBranch`、`BranchTrackingStatus`、`BranchComparison`
- `GitTag`、`GitTagKind`、`TagRemoteStatus`
- `RepositoryRuleset`、`RulesetEnforcement`、`RulesetCondition`
- `GitHubIssue`、`IssueState`、`IssueComment`、`IssueTimelineEvent`
- `IssueMilestone`、`IssueLabel`、`SavedIssueView`、`IssueDraft`

模型只描述数据，不直接执行网络、Git 或界面操作。

### 本地 Git 服务

新增 `LocalRepositoryGitService` 协议和 `ProcessLocalRepositoryGitService` 实现。

服务只允许调用 `/usr/bin/git`，负责：

- `for-each-ref` 读取本地与远端分支、标签和提交信息；
- `status --porcelain` 检查工作区；
- `rev-list --left-right --count` 计算领先与落后；
- 创建、签出、合并、设置上游、推送和删除分支；
- 创建、推送、同步和删除标签。

所有命令参数使用数组传递，不拼接 Shell 字符串。输出日志继续对凭据脱敏。

### GitHub 仓库 API

新增 `GitHubRepositoryAPI` 协议和基于 `URLSession` 的实现，复用现有账户令牌、服务器地址和错误映射。

服务负责：

- 远程分支、提交、Ruleset 和规则详情；
- 议题查询、详情、评论、负责人、标签、里程碑和锁定状态；
- 里程碑与议题标签增删改；
- 速率限制、分页链接和验证错误解析。

GitHub.com 使用 `https://api.github.com`；GitHub Enterprise 使用已标准化的 `/api/v3/`。

### 业务编排

新增 `@MainActor @Observable RepositoryWorkspaceViewModel`，持有：

- 当前账户、仓库和本地目录；
- 第 16–23 页路由；
- 分支、标签、规则集、议题、里程碑和标签状态；
- 搜索、筛选、分页、选中项、加载、错误和危险操作确认状态。

ViewModel 只依赖协议，不直接构造 `URLSession`、`Process` 或 Keychain。

### SwiftUI 页面

新增 `RepositoryWorkspaceRootView`，内部包含统一仓库侧边栏、顶部标题栏和第 16–23 页内容。

主要页面拆分为：

- `BranchesView`、`TagsView`、`BranchRulesView`
- `IssuesOverviewView`、`IssueDetailView`、`NewIssueView`
- `MilestonesCanvasView`、`IssueLabelsView`

通用组件包括列表面板、详情面板、头像、筛选胶囊、Markdown 编辑器外壳、危险确认框和错误横幅。

## 数据流

1. 从账户会话读取当前账户、令牌、仓库和本地目录。
2. 进入分支页面时并行读取本地 Git 引用和 GitHub 远程元数据。
3. 进入议题页面时使用 GitHub 查询加载第一页，并保留服务器返回的下一页链接。
4. 用户操作先由 ViewModel 校验本地状态和权限，再调用对应服务。
5. 写操作成功后局部刷新当前列表和详情；失败时保留用户输入与当前选择。
6. 401 进入授权失效恢复；403 区分权限不足和速率限制；409 与 422 显示 GitHub 返回的具体冲突或字段错误。

## 错误与离线处理

- 网络中断时保留最后一次成功数据并显示离线横幅，写操作暂停。
- 本地 Git 操作失败显示命令、退出码和已脱敏错误摘要。
- 工作区非干净状态不自动覆盖或丢弃文件。
- Ruleset 权限不足时保持只读，不隐藏已有规则。
- 议题发布失败时保留草稿、标签、负责人和里程碑选择。
- 标签合并失败时记录已处理与未处理议题，重试不重复修改成功项。
- 危险操作取消后不改变列表、选择或输入。

## 测试

- 自定义测试运行器继续覆盖全部既有 34 个测试。
- 使用 `FakeCommandExecutor` 测试 Git 命令和参数，不访问真实仓库。
- 使用 `URLProtocolStub` 测试 GitHub REST 请求、分页、错误和 JSON 解析。
- 测试本地与远端分支合并、领先落后、脏工作区拦截和删除确认。
- 测试标签去重、推送、签名状态和远端删除。
- 测试 Ruleset 继承只读和危险变更确认。
- 测试议题查询、评论、编辑、关闭、锁定、草稿恢复和失败保留。
- 测试里程碑画布布局的归一化坐标、点击选择和删除影响。
- 测试标签合并的幂等重试。
- 编译并使用 `--preview-page 16...23` 检查默认与最小窗口高度。

## 验收标准

- 第 16–23 页均可通过开发预览参数独立打开。
- 真实 Git 与 GitHub REST 读写操作通过协议接入，不使用静态假数据作为正式路径。
- 页面在 1180 × 760 和 1040 × 680 下无重叠，底部主操作保持可见。
- 分支、标签、议题、评论、里程碑和标签的支持操作可以成功调用对应服务。
- GitHub 不支持或本阶段不覆盖的操作明确解释并提供网页入口，不展示虚假成功。
- 所有新增测试和既有测试通过，应用编译成功，工作区不包含明文令牌。
