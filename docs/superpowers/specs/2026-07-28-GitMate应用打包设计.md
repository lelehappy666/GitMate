# GitMate 应用打包设计

## 目标

将当前已完成的第 01–09 页原生 macOS 程序打包为单一可双击运行的应用：

```text
dist/GitMate.app
```

## 产物范围

- 只生成 `GitMate.app`
- 不生成 ZIP
- 不生成 DMG
- 不复制到 `/Applications`
- 不修改用户现有应用

## 构建方式

- 使用 Swift Package 的 Release 配置编译 `GitMate`
- 创建标准 macOS 应用包结构
- 将 Release 可执行程序放入 `Contents/MacOS/GitMate`
- 写入 `Contents/Info.plist`
- 应用标识使用 `com.gitmate.app`
- 最低系统版本为 macOS 14
- 使用 ad-hoc 临时签名，不依赖 Developer ID 证书

## 验证

- 验证 Release 编译成功
- 验证 `.app` 目录结构完整
- 使用 `codesign --verify --deep --strict` 验证签名
- 使用 `plutil -lint` 验证 `Info.plist`
- 实际启动 `GitMate.app`，确认登录页窗口显示

## 限制

该产物没有 Apple Developer ID 正式签名和公证。当前 Mac 可以用于开发预览；复制到其他 Mac 后，首次运行可能需要在访达中右键选择“打开”。
