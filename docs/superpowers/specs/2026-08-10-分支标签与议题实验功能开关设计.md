# 分支标签与议题实验功能开关设计

## 背景

当前版本已提供分支、标签、分支规则、议题、议题详情、新建议题、里程碑和议题标签等仓库管理能力。当前产品暂时不需要展示这组功能，但需要保留未来重新启用的能力。

本次不删除功能代码，而是增加一个默认关闭、可持久化的实验功能开关，将整组管理功能从默认工作流中移除。

## 目标

1. 默认不展示“分支、标签与议题”入口。
2. 用户可以在“设置 → 实验功能”中重新启用整组功能。
3. 开关状态在应用重启后保留。
4. 关闭功能时不创建仓库管理运行时，不发起分支、标签或议题相关网络请求。
5. 保留提交图所需的本地 Git 只读分支关系、分支筛选和提交拓扑能力。

## 非目标

- 不删除 GitHub 上的任何远程分支、标签、规则、议题、里程碑或议题标签。
- 不删除 Git 开发分支 `feature/分支标签与议题`。
- 不改变提交图中的分支展示和操作。
- 不重新设计已有管理页面。
- 不删除已有的本地议题草稿或设置数据；开关重新开启后仍可继续使用。

## 用户体验

### 默认状态

- 全局工作区侧边栏不显示“分支、标签与议题”入口。
- 隐藏后不保留灰色占位，其他导航项目自然收紧。
- “提交图”仍正常显示并保留分支关系。

### 设置入口

- 全局工作区侧边栏底部的“设置”从静态文字改为可点击按钮。
- 仓库管理工作区侧边栏底部的“仓库设置”打开同一个设置弹窗，使用户可在管理页面中关闭实验功能。
- 点击后打开原生 macOS 设置弹窗。
- 弹窗中提供“实验功能”分组，包含“分支、标签与议题管理”开关。
- 开关附带说明：启用后可以管理 GitHub 分支、标签、规则和议题；该功能仍处于实验阶段。

### 开启状态

- 开关开启后，侧边栏立即显示“分支、标签与议题”入口。
- 点击入口后继续使用现有的管理工作区，其页面、网络接口和错误处理保持不变。

### 使用中关闭

- 如果用户正在管理工作区中关闭开关，应立即退回全局工作区。
- 已经发起的页面任务随视图销毁而取消，不再显示管理页面。
- 不删除用户的 GitHub 数据或本地草稿。

## 状态与持久化

新增单一职责的实验功能偏好存储，负责读取和保存仓库管理开关。

- 默认值：`false`。
- 存储位置：当前 macOS 用户的 `UserDefaults`。
- 作用域：全局，不按 GitHub 账户或仓库区分。
- 观察方式：根视图、全局侧边栏与设置弹窗共享同一个可观察状态，切换后立即更新界面。

## 组件变更

### 实验功能偏好

增加可注入、可测试的偏好存储和可观察界面模型。生产环境使用 `UserDefaults`，测试使用内存实现，避免测试污染真实用户设置。

### 设置弹窗

增加独立设置视图，只负责展示实验功能开关及说明。全局工作区和仓库管理工作区的侧边栏都通过回调打开同一个设置弹窗，不直接读写 `UserDefaults`。

### 全局工作区侧边栏

侧边栏根据共享偏好状态决定是否构建“分支、标签与议题”操作按钮。关闭时按钮不进入视图树，因此不会留下空白占位或可访问性节点。

### 根视图安全门

打开管理工作区前再次检查开关，避免仅依赖侧边栏隐藏。开关关闭后，如果当前已经存在管理运行时，根视图清除该运行时并回到原工作区。

## 数据与网络边界

- 关闭状态下不调用仓库管理运行时工厂。
- 因为不创建管理运行时，所以不会为隐藏功能构建请求上下文，也不会加载对应页面。
- 提交图、仓库总览、README、文件与提交继续使用它们原有的读取服务，不受开关影响。

## 错误与边界处理

- 持久化未存在时使用默认关闭状态。
- 从旧版本升级时不继承之前默认可见的状态，新开关仍为关闭。
- 开关关闭后，任何新的管理工作区打开请求都被根视图忽略。
- 设置弹窗关闭不影响已保存的开关值。

## 测试与验收

### 自动测试

1. 偏好存储在没有已保存值时返回 `false`。
2. 保存开启或关闭状态后可以稳定读回。
3. 不同测试存储实例相互隔离。
4. 关闭状态拒绝打开管理工作区。
5. 关闭开关时清除已存在的管理运行时。
6. 现有核心测试全部通过，确认提交图与仓库阅读功能没有回归。

### 界面验收

1. 新安装启动后，侧边栏不显示“分支、标签与议题”。
2. 点击全局工作区的“设置”或仓库管理工作区的“仓库设置”，都可打开“实验功能”弹窗。
3. 开启开关后入口立即出现，且可打开原有管理工作区。
4. 在仓库管理工作区中关闭开关后立即退回全局工作区，入口同时消失。
5. 重启应用后保持最后一次选择的开关状态。
6. 关闭状态下提交图仍正常显示分支关系和分支筛选。

## 发布方式

实施完成后在当前 `feature/分支标签与议题` 分支执行完整构建和测试，然后重新生成本地签名的 macOS 测试应用与压缩包。
