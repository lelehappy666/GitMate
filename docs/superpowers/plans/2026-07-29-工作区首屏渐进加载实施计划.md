# 工作区首屏渐进加载实施计划

> **供代理执行：** 必须逐项使用测试驱动开发，先验证失败，再写最小实现。

**目标：** 先发布缓存与本地记录首屏，再以最多 4 个仓库并发逐仓库刷新页面 10/11。

**架构：** `WorkspaceDashboardLoading` 提供增量快照流；服务用有界任务组产生首屏和逐仓库快照，旧单次 API 消费流并返回最终值。两个 ViewModel 原位应用快照，页面 11 容器只消费流，不重建筛选状态。

**技术栈：** Swift 6、Foundation 并发、Observation、现有 `GitMateCoreTestsRunner`。

## 全局约束

- 文档、测试名称和提交信息均使用中文。
- 最大仓库刷新并发默认为 4，并限制在 1 至 8。
- 消费者取消必须取消生产任务，缓存继续使用原子 `update`。
- 不修改 Onboarding 与 `WorkspaceRuntimeDependencies`。
- `WorkspaceRootView` 只允许修改 `RepositoryWallContainer`。
