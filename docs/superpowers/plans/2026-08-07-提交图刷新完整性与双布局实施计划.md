# 提交图刷新、完整性与双布局实施计划

> **面向代理执行者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项实施。所有步骤使用复选框跟踪。

**目标：** 为提交图增加可靠刷新、完整性校验、50,000 提交可视区域渲染，以及 GitKraken 式传统分支图与无限画布双布局。

**架构：** 使用 `CommitGraphSnapshot` 保存唯一 Git 拓扑，使用 `CommitGraphSceneState` 保存唯一用户场景状态，再从两者派生传统泳道和画布渲染索引。刷新协调器先复用正确缓存，再根据引用指纹决定是否完整扫描；只有通过完整性校验的候选快照可以替换当前数据。

**技术栈：** Swift 6、SwiftUI、Observation、Foundation、现有命令执行器、二进制 Property List、现有自定义测试运行器。

## 全局约束

- 平台保持 macOS 14，不增加第三方依赖。
- 所有界面文字、文档和 Git 提交信息使用中文。
- 只读取本地 Git，不执行 fetch、pull、reset 或其他仓库写操作。
- 刷新保留视口、缩放、手动位置、分组、折叠、固定端口和版本区域。
- 传统布局最新提交在上、最早提交在下；画布布局最早提交在上、最新提交在下。
- Group 禁止嵌套；直角连线不做自动避障。
- 50,000 提交场景不得在每一帧遍历完整节点与连线集合。

- [ ] **步骤 3：实现二进制 Property List 存储**

```swift
public protocol CommitGraphSnapshotStoring: Sendable {
    func load(repositoryID: Int64) async throws -> CommitGraphSnapshot?
    func save(_ snapshot: CommitGraphSnapshot, repositoryID: Int64) async throws
}

public actor BinaryCommitGraphSnapshotStore: CommitGraphSnapshotStoring {
    public func save(
        _ snapshot: CommitGraphSnapshot,
        repositoryID: Int64
    ) async throws {
        try fileManager.createDirectory(at: rootDirectory, withIntermediateDirectories: true)
        let encoder = PropertyListEncoder()
        encoder.outputFormat = .binary
        let data = try encoder.encode(snapshot)
        try data.write(to: snapshotURL(repositoryID), options: .atomic)
    }
}
```

加载时验证 `schemaVersion`，临时文件不得被识别为正式缓存。

`.atomic` 写入必须落在目标缓存同一目录，确保文件系统执行原子替换。

            authoredAt: Date(timeIntervalSince1970: Double(index)),
            parentHashes: index == 0 ? [] : ["hash-\(index - 1)"],
            decorations: index == count - 1 ? ["HEAD -> main"] : []
        )
    }
    return CommitGraphSnapshot(
        repositoryPath: "/performance",
        fingerprint: CommitGraphReferenceFingerprint(
            references: [
                CommitGraphReference(
                    name: "refs/heads/main",
                    targetHash: "hash-\(count - 1)",
                    kind: .localBranch
                )
            ],
            headName: "main",
            headHash: "hash-\(count - 1)",
            isShallow: false
        ),
        commitsNewestFirst: commits,
        expectedCommitCount: count,
        shallowBoundaryParentHashes: [],
        generatedAt: Date(timeIntervalSince1970: 0)
    )
}

private func makeProjection(
    _ snapshot: CommitGraphSnapshot
) -> CommitGraphSceneProjection {
    let layout = CommitGraphLayout().layout(snapshot: snapshot)
    return CommitGraphSceneProjector.project(
        layout: layout,
        scene: .defaultState(layout: layout)
    )
}
