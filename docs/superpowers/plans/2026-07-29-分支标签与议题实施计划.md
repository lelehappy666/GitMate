# 分支、标签与议题功能实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 GitMate 中实现第 16–23 页，使分支、标签、Ruleset、议题、评论、里程碑和议题标签具备真实本地 Git 与 GitHub REST 读写能力。

**Architecture:** `GitMateCore` 增加领域模型、本地 Git 服务、GitHub REST 服务、持久化存储和 `RepositoryWorkspaceViewModel`。`GitMateApp` 增加统一仓库工作区外壳与八个 SwiftUI 页面，正式运行使用真实服务，`--preview-page 16...23` 使用隔离预览数据。

**Tech Stack:** Swift 6、SwiftUI、Observation、Foundation、Security、系统 `/usr/bin/git`、GitHub REST API 2022-11-28、自定义异步测试运行器。

## Global Constraints

- 执行前必须使用 `superpowers:using-git-worktrees` 从当前 `HEAD` 创建独立工作树，原工作区未提交改动不得暂存、提交、覆盖或移动。
- 工作树分支固定使用 `feature/分支标签与议题`；如果已存在则复用对应工作树，不重新创建分支。
- 平台最低版本为 macOS 14，禁止新增第三方运行时依赖。
- 所有文档、界面文案和 Git 提交必须使用中文。
- 默认窗口为 1180 × 760，最小窗口为 1040 × 680；列表只在面板内部滚动。
- 正式路径必须使用真实 Git 和 GitHub REST，预览假数据只能存在于 `GitMateApp` 预览依赖中。
- 所有 Git 命令通过参数数组执行，禁止拼接 Shell；所有日志和错误不得包含明文令牌。
- 危险操作必须在 ViewModel 中产生结构化确认请求，视图确认后才能调用服务。
- GitHub 不支持的议题删除、REST 范围外的转移和转换讨论只提供解释与网页入口。
- 每个任务先写失败测试、确认失败、实现最小代码、运行全部测试、再使用中文提交。
