# 里程碑创建与错误反馈修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复新建里程碑时的 GitHub 422 `Invalid request.`，并让失败时的表单、权限提示和字段错误都可理解、可重试。

**Architecture:** 保留领域层 `MilestoneInput`，在 GitHub Issues API 适配层分别使用创建请求体与更新请求体：创建时省略空可选字段，更新时显式发送 `null` 以支持清空。REST 客户端保留 GitHub 422 的结构化详情，ViewModel 返回成功状态，SwiftUI 表单在异步保存成功前保持打开并展示行内错误。

**Tech Stack:** Swift 6、SwiftUI、Foundation URLSession、JSONEncoder/JSONDecoder、自定义可执行测试运行器。

## Global Constraints

- 支持 macOS 14 及以上版本。
- 所有界面文案、测试说明和文档使用中文。
- Git 提交信息使用中文。
- 创建里程碑时，`description == nil` 与 `dueOn == nil` 必须从 JSON 中省略，不得编码为 `null`。
- 更新里程碑时，空描述或取消截止日期必须显式编码为 `null`。
- GitHub 日期使用 UTC ISO 8601 `YYYY-MM-DDTHH:MM:SSZ`。
- 保存期间禁止重复提交和关闭表单；仅成功后关闭，失败时保留所有输入。
- 422 必须显示 resource、field、code、message 中 GitHub 实际返回的可用详情；403 必须提示需要 Issues 或 Pull Requests 写权限。

- [ ] **Step 3: 实现私有传输请求体**

```swift
private struct CreateMilestonePayload: Encodable {
    let title: String
    let description: String?
    let state: IssueState
    let dueOn: Date?

    func encode(to encoder: Encoder) throws {
        var container = encoder.container(keyedBy: CodingKeys.self)
        try container.encode(title, forKey: .title)
        try container.encode(state, forKey: .state)
        try container.encodeIfPresent(description, forKey: .description)
        if let dueOn {
            try container.encode(Self.formatter.string(from: dueOn), forKey: .dueOn)
        }
    }
}
```

`UpdateMilestonePayload.encode(to:)` 对 nil 使用 `encodeNil(forKey:)`。两者共用固定 UTC 的 `ISO8601DateFormatter`，`formatOptions = [.withInternetDateTime]`，`timeZone = TimeZone(secondsFromGMT: 0)`。`MilestoneInput` 移除 `Encodable` 和自定义编码器，只保留 `Equatable, Sendable`。

- [ ] **Step 2: 实现稳定的呈现身份与异步保存**

```swift
private struct MilestoneEditorPresentation: Identifiable {
    let id = UUID()
    let milestone: IssueMilestone?
}
```

父视图保存函数返回错误消息，成功时再清空呈现：

```swift
@MainActor
private func saveMilestone(_ input: MilestoneInput) async -> String? {
    let succeeded: Bool
    if let milestone = editorPresentation?.milestone {
        succeeded = await viewModel.updateMilestone(number: milestone.number, input: input)
    } else {
        succeeded = await viewModel.createMilestone(input)
    }
    guard succeeded else { return viewModel.state.errorMessage ?? "保存里程碑失败，请重试。" }
    editorPresentation = nil
    return nil
}
```

- [ ] **Step 3: 实现表单保存状态与行内错误**

`MilestoneEditorSheet` 新增：

```swift
@State private var isSaving = false
@State private var errorMessage: String?
let onSave: @MainActor (MilestoneInput) async -> String?
```

保存按钮启动 `Task`，保存前清空错误并设置 `isSaving = true`，完成后恢复；返回非 nil 时用红色 `Label(errorMessage, systemImage: "exclamationmark.triangle.fill")` 显示。保存期间：取消和保存按钮都禁用，保存按钮标题显示 `ProgressView()` 与“正在保存…”。标题、描述、状态和日期 State 不重建，因此错误后完整保留。
