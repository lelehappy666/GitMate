# 提交分组折叠与多格式文件预览实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 GitMate macOS 应用中完成提交 Group 折叠与动态连线、节点和 Group 拖动、场景持久化、提交文字边界修复，以及图片、PDF、安全 HTML、Markdown 和脚本文件预览。

**Architecture:** 保留 `CommitGraphLayoutResult` 作为不可变 Git 拓扑和初始布局，在 Core 中新增可持久化场景、分组投影、固定端口和路径纯函数；SwiftUI/AppKit 层只绘制场景并通过 `CADisplayLink`合并拖动。文件预览由 Core 分类策略产生不可执行的预览文档，App 层分别使用源码视图、`NSImage`、`PDFKit`和受限 `WKWebView`渲染。

**Tech Stack:** Swift 6、SwiftUI、AppKit、Observation、Canvas、QuartzCore `CADisplayLink`、PDFKit、WebKit、Foundation JSON、自定义 `GitMateCoreTestsRunner`。

## 全局约束

- 所有文档和提交信息使用中文。
- 不引入第三方依赖，不修改无关页面。
- HTML 禁用 JavaScript、网络、本地文件和外部导航。
- `Command`切换选择，`Shift`追加选择且不实现范围选择。
- 自动分组只生成建议，用户确认后才创建。
- 一个提交最多属于一个 Group。
- Group 只保存 `origin`，成员只保存相对坐标。
- 聚合键使用 `groupId + externalNodeId + direction`。
- 固定端口创建后，移动、缩放、折叠和线型切换均不重新分配。
- Group 成员变化仅更新受影响端口，未变化聚合键复用原端口。
- 直角折线两端先伸出 28px，不做自动避障。
- 所有生产代码遵循测试先失败、最小实现、测试转绿的顺序。
