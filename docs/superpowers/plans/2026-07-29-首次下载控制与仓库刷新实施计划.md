# GitMate 首次下载控制与仓库刷新实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 将仓库同步方式改为复选框选择的首次 Clone 流程，并实现立即暂停/继续、双进度条与 GitHub 云端仓库刷新。

**架构：** `OnboardingState` 使用仓库编号集合表达首次下载选择，不再保存同步模式。`ProcessCommandExecutor` 管理当前 Git 子进程的挂起与恢复，`GitRepositorySyncService` 解析 Git 输出并向 ViewModel 上报当前仓库进度；SwiftUI 页面只渲染状态并调用 ViewModel 命令。

**技术栈：** Swift 6、SwiftUI、Observation、Foundation `Process`、AsyncThrowingStream、macOS 14。

## 全局约束

- 所有用户界面、错误提示、设计文档和 Git 提交信息使用中文。
- 删除“自动同步”“不同步”“手动”三个同步方式选项。
- 仓库默认全部未勾选，只 Clone 用户勾选的仓库。
- 暂停必须挂起当前 Git 进程，继续必须恢复同一个进程。
- 首次下载不得隐式执行 Fetch、Pull 或 Push。
- 保持大量仓库的惰性渲染和后台 Git 执行。
