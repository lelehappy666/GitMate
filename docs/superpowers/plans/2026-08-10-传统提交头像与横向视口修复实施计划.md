# 传统提交头像与横向视口修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 修复传统提交视图头像穿透固定头部与真实头像缺失问题，并让提交内容在固定头部下支持鼠标拖动和触控板横向滚动。

**架构：** 在 GitMateCore 中新增纯函数形式的头像身份解析和横向视口几何，保证规则可独立测试；应用层将固定头部与可移动提交内容拆成两个裁剪层，Canvas、头像和无障碍行共享同一横向偏移。AppKit 交互层只负责把滚轮与拖动增量转交给 SwiftUI，点击选择由拖动阈值保护。

**技术栈：** Swift 6、SwiftUI、AppKit、Swift Package Manager、自定义 GitMateCoreTestsRunner。

## 全局约束

- 不新增 GitHub API 请求，只使用提交邮件、当前账户资料和既有头像缓存。
- 固定“工作区变更”和分支栏，只有下方提交内容整体横向移动。
- 头像与无障碍覆盖层只创建真实可见行；Canvas 可以继续预加载邻近行。
- 横向偏移限制在 `0...max(contentWidth - viewportWidth, 0)`，不露出空白区域。
- 鼠标拖动超过阈值后不得触发行选择；简单点击仍打开提交详情。
- 当前账户显示名参与头像匹配；无法解析头像时使用最多两个字符的作者首字母和稳定颜色。
- 所有文档与 Git 提交信息使用中文。

### 任务 3：固定头部下的整体横向视口

**文件：**
- 修改：`Sources/GitMateApp/Workspace/Repository/CommitGraphTraditionalView.swift`

**接口：**
- 新增瞬态 `@State private var horizontalOffset = 0.0`。
- `TraditionalInteractionSurface` 的 `scroll` 同时返回垂直与横向增量，并增加拖动生命周期；拖动结束只有未超过阈值时才调用 `selectRow`。
- Canvas、头像层、无障碍层放入同一个 `contentWidth` 容器并统一 `.offset(x: -horizontalOffset)`。

- [ ] **步骤 1：拆分预加载行和覆盖层可见行**

Canvas 使用当前 `preloadScreens: 1.5` 的行范围；头像和无障碍层使用 `CommitGraphTraditionalContentViewport.overlayRows(...)`。提交内容容器和最外层 GeometryReader 均应用 `.clipped()`，确保任何 SwiftUI 子视图都不能穿透固定头部。

- [ ] **步骤 2：建立虚拟内容宽度与统一偏移**

```swift
let contentWidth = CommitGraphTraditionalContentViewport.contentWidth(
    viewportWidth: width,
    maximumLane: max(branchProjection.slots.count - 1, 0)
)

ZStack(alignment: .topLeading) {
    CommitGraphTraditionalCanvas(...)
    avatarLayer(...)
    accessibilityRows(...)
}
.frame(width: contentWidth, height: height)
.offset(x: -horizontalOffset)
```

交互层保持在可视窗口坐标系，不跟随内容偏移。

- [ ] **步骤 3：实现触控板横向滚动与鼠标拖动**

精确滚轮读取 `scrollingDeltaX`；Shift+滚轮作为横向滚动。鼠标按下只记录起点和候选行，拖动累计距离超过 4pt 后进入拖动态，每次把横向增量交给 SwiftUI，鼠标抬起时仅非拖动态选择提交行。

- [ ] **步骤 4：实现边界夹紧与仓库切换复位**

布局、视口尺寸或分支槽数量变化时用纯函数夹紧；传统视图重新创建时初始偏移为 0。横向滚轮和鼠标向右拖动的内容方向遵循 macOS 直接操控习惯，并在最大边界停止。
