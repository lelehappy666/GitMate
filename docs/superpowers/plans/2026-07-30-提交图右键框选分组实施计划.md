# 提交图右键框选分组实施计划

## 目标

在现有无限画布和提交分组架构上增加右键框选、边缘自动滚动、松手校验并创建分组的完整交互，不改动 Git 拓扑和已有分组模型。

## 技术方案

- 复用 `CommitGraphInteractionSurface` 的 AppKit 事件处理与 `CADisplayLink` 帧合并机制。
- 用画布坐标保存框选起点，用当前视口反算指针对应的画布坐标。
- 在交互层直接绘制框选矩形、卡片高亮和计数标签。
- 在 `CommitGraphViewModel` 中增加替换选择与建组前校验接口。
- 在 `CommitGraphView` 中接收框选结果，根据校验结果打开命名弹窗或显示错误提示。

## 实施步骤

### 1. 扩展交互层回调

- 为 `CommitGraphInteractionSurface` 增加框选完成回调。
- 在 Coordinator 中保存并转发回调，保持 SwiftUI 更新时闭包可替换。

### 2. 实现右键框选状态机

- 处理 `rightMouseDown`、`rightMouseDragged`、`rightMouseUp`。
- 仅允许从空白画布启动。
- 计算选择矩形与提交卡片的相交关系。
- 直接绘制半透明框、命中卡片高亮与选择数量。

### 3. 实现边缘自动滚动

- 增加 40 点边缘热区和渐进速度计算。
- 在显示帧回调中持续平移视口，并在同一帧刷新框选命中。
- 鼠标离开热区或松开右键后暂停帧调度。

### 4. 接入分组校验和创建

- ViewModel 增加按哈希集合替换当前选择的方法。
- ViewModel 增加不改变状态的手动分组选择校验。
- 视图接收框选结果；有效时打开分组名称输入框，无效时保留选择并显示原因。
- 工具栏和画布提示改为右键框选说明。

### 5. 构建与交付

- 检查代码差异和格式问题。
- 按用户要求不运行测试。
- 执行 Release 构建，重新生成并签名 `GitMate.app`。
