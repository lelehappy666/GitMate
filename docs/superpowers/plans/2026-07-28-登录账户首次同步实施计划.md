# 登录、账户与首次同步实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 GitMate 第 01–09 页对应的原生 macOS 登录、账户验证、权限确认、仓库同步配置、首次同步进度及异常恢复流程。

**Architecture:** 使用 Swift Package 管理 `GitMateCore`、`GitMateApp` 和测试目标。核心层通过状态机驱动页面，GitHub API、钥匙串、网络和 Git 命令均以协议隔离；SwiftUI 视图只绑定 `OnboardingViewModel`，不直接执行网络或文件系统操作。

**Tech Stack:** Swift 6、SwiftUI、Observation、Foundation、Security、URLSession、XCTest、系统 Git。

## Global Constraints

- 目标平台为 macOS 14 及以上。
- 所有用户可见文案使用中文。
- 页面 01 只提供登录入口，不展示冗长产品介绍。
- 页面 01–09 使用白色主色调、高对比文字和固定窗口高度。
- 页面 06 使用横向进度条并实时显示同步文件。
- 页面 07–09 分别覆盖同步错误、网络中断和授权失效。
- GitHub 用户位置使用真实头像 URL，仓库位置可以使用仓库图标。
- GitHub.com 使用 Device Flow；客户端 ID 从 `GITMATE_GITHUB_CLIENT_ID` 或应用配置读取。
- GitHub Enterprise 使用服务器地址和 Personal Access Token 验证。
- 访问令牌只写入 macOS 钥匙串，不写入 UserDefaults、日志或仓库文件。
- 仓库同步模式支持不同步、手动同步和自动同步。
- 本阶段不实现第 10 页及之后的功能。
- 所有 Git 提交信息使用中文。

- [ ] **Step 3: 实现最小状态模型**

```swift
public struct OnboardingState: Equatable, Sendable {
    public var route: OnboardingRoute
    public var account: GitHubAccount?
    public var repositories: [Repository]
    public var preferences: [RepositorySyncPreference]
    public var progress: SyncProgress
    public var canResumeSync: Bool
    public var errorMessage: String?

    public mutating func transition(_ event: OnboardingEvent) {
        switch event {
        case .loginRequested:
            route = .githubAuthorization
        case let .accountVerified(account):
            self.account = account
            route = .permissionReview
        case .networkLost:
            canResumeSync = true
            route = .networkInterrupted
        default:
            break
        }
    }
}
```
