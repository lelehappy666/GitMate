# GitMate 全局与仓库页面 10–15 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有登录与首次同步功能之上，实现可真实运行的全局工作台、仓库封面墙、仓库总览、README、文件与提交以及无限画布提交图。

**Architecture:** 使用本地优先混合架构。本地 Git 是文件、提交和关系图的事实来源，GitHub API 只补充在线摘要；独立服务通过 `WorkspaceContentService` 合并后交给每页 ViewModel。SwiftUI 页面不直接执行网络、Git 或文件系统操作。

**Tech Stack:** Swift 6、SwiftUI、Observation、Foundation、URLSession、系统 `/usr/bin/git`、现有轻量测试运行器 `GitMateCoreTestsRunner`。

## Global Constraints

- 目标平台为 macOS 14 或更高版本。
- 开发范围严格限定为页面 10–15。
- 不实现议题、拉取请求、Actions 等详情工作流。
- 不实现 checkout、reset、cherry-pick、merge、rebase 等 Git 写操作。
- 不恢复收件箱或项目模块。
- 主窗口默认尺寸 1180×760，最小尺寸 1040×680。
- 主窗口不产生纵向页面滚动，内容只在面板内部滚动或在画布内部移动。
- 主色调为白色，正文使用高对比深色，GitHub 用户位置使用真实头像。
- Token 只从钥匙串读取，不得进入缓存、日志、命令参数或 Git 远程地址。
- 所有文档和 Git 提交使用中文。
- 当前工作区存在其他未提交改动；每次只使用精确路径 `git add`，不得覆盖、暂存或提交无关改动。
- 当前环境缺少 XCTest/Swift Testing 模块，测试统一通过 `GitMateCoreTestsRunner` 执行。

```swift
public enum WorkspaceRoute: Equatable, Sendable {
    case dashboard
    case repositories
    case repositoryOverview(repositoryID: Int64)
    case readme(repositoryID: Int64)
    case filesAndCommits(repositoryID: Int64)
    case commitGraph(repositoryID: Int64)

    public var pageNumber: Int {
        switch self {
        case .dashboard: 10
        case .repositories: 11
        case .repositoryOverview: 12
        case .readme: 13
        case .filesAndCommits: 14
        case .commitGraph: 15
        }
    }

    public var repositoryID: Int64? {
        switch self {
        case .dashboard, .repositories:
            nil
        case let .repositoryOverview(id),
             let .readme(id),
             let .filesAndCommits(id),
             let .commitGraph(id):
            id
        }
    }
}

public struct WorkspaceSession: Equatable, Sendable {
    public let account: GitHubAccount
    public var repositories: [Repository]
    public var route: WorkspaceRoute
}

public struct RepositoryOnlineSummary: Equatable, Codable, Sendable {
    public let repositoryID: Int64
    public let primaryLanguage: String?
    public let openIssueCount: Int
    public let openPullRequestCount: Int
    public let failedWorkflowCount: Int
    public let remoteUpdatedAt: Date?
}
```

`CommandLocalGitReader` 只能调用以下命令形态：

```text
git -C <repo> status --porcelain=v2 --branch -z

git -C <repo> show <revision>:<path>
git -C <repo> log --format=<字段格式> -n <limit> [--skip <offset>]
```

```swift
    public let childHash: String
    public let parentHash: String
    public let kind: CommitGraphEdgeKind
    public let colorIndex: Int
}
```

布局规则：

- 第一父提交尽量继承当前列。
- 额外父提交分配最近的空闲列并标记 `.merge`。
- 分支和标签颜色根据稳定字符串哈希生成。
- 新分页追加时保留已有节点的列。
- 节点间距固定，避免同一输入每次跳动。
