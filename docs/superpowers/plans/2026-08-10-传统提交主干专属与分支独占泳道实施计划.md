# 传统提交主干专属与分支独占泳道实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 让传统提交图的第 0 泳道永久专属于逻辑 `main`，没有 `main` 时保持空白，并让每个非主干分支只在自己的泳道绘制独有提交区段，通过关系连线连接共享祖先与 Merge。

**架构：** 在现有完整快照派生链中增加独立的传统区段投影：分支投影负责逻辑引用配对与固定泳道，区段投影负责提交到泳道、稳定颜色与跨泳道边。Canvas 只消费最终投影，不再在绘制时通过 `branchCatalog.branch(containing:)` 猜测提交归属。

**技术栈：** Swift 6、SwiftUI Canvas、AppKit、Swift Package Manager、自定义 `GitMateCoreTestsRunner`。

## 全局约束

- 所有文档和 Git 提交信息使用中文。
- 第 0 泳道永久保留给逻辑 `main`；没有任何本地或远程 `main` 时保持空白。
- 每个非主干逻辑分支独占泳道，分支关系仅由连线表达。
- 可线性衔接的本地与同名远程分支共用逻辑泳道；真正分叉时拆成相邻泳道。
- 共享提交只绘制一次，不为每个可达分支复制节点。
- 最新提交在上、最早提交在下。
- 滚动、分割线拖动和提交选择不得重新计算 Git 拓扑。
- 完整开发结束后统一运行全量测试、Debug/Release 构建并重新打包。

- [ ] **步骤 3：实现不可变区段投影模型**

```swift
public struct CommitGraphTraditionalSegmentProjection: Equatable, Sendable {
    public let connections: [CommitGraphTraditionalSegmentConnection]
    private let laneByHash: [String: Int]
    private let colorIndexByHash: [String: Int]

    public func lane(for hash: String) -> Int? { laneByHash[hash] }
    public func colorIndex(for hash: String) -> Int? { colorIndexByHash[hash] }
}

public struct CommitGraphTraditionalSegmentConnection: Identifiable, Equatable, Sendable {
    public let childHash: String
    public let parentHash: String
    public let sourceLane: Int
    public let targetLane: Int
    public let kind: CommitGraphEdgeKind
    public let colorIndex: Int
}
```

实现顺序：逻辑 `main` 第一父链先归属第 0 泳道；其他逻辑分支按稳定槽位顺序领取从 tip 到首个已归属祖先之间的提交；剩余 detached/synthetic 组件归入自身槽位。所有父边使用最终 `laneByHash` 生成，禁止在绘制阶段重新判定。
