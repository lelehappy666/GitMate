# 提交图分组管理与版本区域实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复框选状态残留，完善分组管理，增加可编辑的大版本区域标识、真实分支图例，并恢复 HTML 完整脚本运行。

**Architecture:** 保持 `CommitGraphSceneState` 为画布唯一持久化状态，在其上增加独立的区域标识集合；分组仍是扁平提交集合，由核心层统一校验成员关系。AppKit 交互层负责右键命中、框选、拖动与原生菜单，SwiftUI 负责编辑弹窗和工具栏状态，投影和 Git 拓扑继续由现有核心层生成。

**Tech Stack:** Swift 6、SwiftUI、AppKit、WebKit、Observation、Swift Package Manager

## Global Constraints

- 所有文档和 Git 提交使用中文。
- macOS 最低版本保持 14.0。
- 分组严格禁止嵌套，区域标识不参与 Git 拓扑和分组关系。
- 自动布局、聚焦分支、缩放和线型切换不得改变分组、折叠及区域状态。
- HTML JavaScript 运行在独立 `WKWebView` 中，不提供 GitMate 原生桥接。
