# GitMate 应用打包实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 生成唯一可交付产物 `dist/GitMate.app`。

**Architecture:** 使用 Swift Package Release 配置编译现有 `GitMate` 可执行程序，再组装标准 macOS `.app` 目录结构。应用使用固定 `Info.plist` 元数据和 ad-hoc 临时签名，不生成 ZIP 或 DMG。

**Tech Stack:** Swift 6、Swift Package Manager、macOS App Bundle、codesign、plutil

## Global Constraints

- 只生成 `dist/GitMate.app`
- 不生成 ZIP 或 DMG
- 不复制到 `/Applications`
- 应用标识固定为 `com.gitmate.app`
- 最低系统版本为 macOS 14
- 所有文档与 Git 提交使用中文

---

### Task 1: 添加应用包元数据

**Files:**
- Create: `packaging/GitMate-Info.plist`
- Modify: `.gitignore`

**Interfaces:**
- Produces: 标准 macOS 应用包元数据
- Consumes: Release 可执行程序名 `GitMate`

- [ ] **Step 1: 创建 Info.plist**

写入：

```xml
<key>CFBundleExecutable</key>
<string>GitMate</string>
<key>CFBundleIdentifier</key>
<string>com.gitmate.app</string>
<key>CFBundleName</key>
<string>GitMate</string>
<key>CFBundlePackageType</key>
<string>APPL</string>
<key>LSMinimumSystemVersion</key>
<string>14.0</string>
```

- [ ] **Step 2: 忽略本地打包目录**

在 `.gitignore` 增加：

```text
dist/
```

- [ ] **Step 3: 验证元数据**

Run:

```bash
plutil -lint packaging/GitMate-Info.plist
```

Expected: `packaging/GitMate-Info.plist: OK`

### Task 2: 编译并组装 GitMate.app

**Files:**
- Create: `dist/GitMate.app/Contents/Info.plist`
- Create: `dist/GitMate.app/Contents/MacOS/GitMate`

**Interfaces:**
- Consumes: `packaging/GitMate-Info.plist`、`.build/release/GitMate`
- Produces: `dist/GitMate.app`

- [ ] **Step 1: 运行 Release 构建**

Run:

```bash
CLANG_MODULE_CACHE_PATH=.build/clang-module-cache \
SWIFT_MODULECACHE_PATH=.build/swift-module-cache \
swift build -c release --product GitMate --disable-sandbox
```

Expected: `Build complete!`

- [ ] **Step 2: 确认输出目录尚不存在**

Run:

```bash
test ! -e dist/GitMate.app
```

Expected: exit 0。若已存在则停止，不覆盖旧产物。

- [ ] **Step 3: 创建应用结构**

Run:

```bash
mkdir -p dist/GitMate.app/Contents/MacOS dist/GitMate.app/Contents/Resources
cp .build/release/GitMate dist/GitMate.app/Contents/MacOS/GitMate
cp packaging/GitMate-Info.plist dist/GitMate.app/Contents/Info.plist
chmod 755 dist/GitMate.app/Contents/MacOS/GitMate
```

- [ ] **Step 4: 添加临时签名**

Run:

```bash
codesign --force --deep --sign - dist/GitMate.app
```

Expected: exit 0。

### Task 3: 验证并交付应用

**Files:**
- Verify: `dist/GitMate.app`

**Interfaces:**
- Consumes: `dist/GitMate.app`
- Produces: 已验证的可双击应用

- [ ] **Step 1: 验证应用结构和签名**

Run:

```bash
plutil -lint dist/GitMate.app/Contents/Info.plist
codesign --verify --deep --strict --verbose=2 dist/GitMate.app
test -x dist/GitMate.app/Contents/MacOS/GitMate
```

Expected: Info.plist 合法、签名有效、主程序可执行。

- [ ] **Step 2: 启动应用**

Run:

```bash
open -n dist/GitMate.app
```

Expected: 显示 GitMate 第 01 页登录窗口。

- [ ] **Step 3: 提交可重复打包配置**

Run:

```bash
git add .gitignore packaging/GitMate-Info.plist docs/superpowers/plans/2026-07-28-GitMate应用打包实施计划.md
git commit -m "添加 GitMate 应用打包配置"
```

产物 `dist/GitMate.app` 保持为本地交付文件，不提交到 Git。
