# GitMate 本地仓库导入与仓库页布局修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 支持原地登记已有 GitHub 仓库，并修复云端仓库卡片、工具栏和语言筛选。

**Architecture:** 核心层新增只读导入器和按账户持久登记存储，
`LocalRepositoryCatalog` 统一解析默认同步目录与外部登记目录。应用层通过
`NSOpenPanel` 选择目录，导入成功后重建本地仓库工作区；云端语言直接来自
GitHub 仓库列表响应，卡片与工具栏只调整布局，不改变分页和封面调度。

**Tech Stack:** Swift 6、SwiftUI、AppKit、Foundation、CryptoKit、系统 Git。

## Global Constraints

- 所有文档和 Git 提交使用中文。
- macOS 最低版本保持 14.0。
- 导入已有仓库时不复制、不移动、不链接、不修改仓库文件。
- 只运行只读 Git 命令，命令参数不得拼接为 shell 字符串。
- 访问令牌和带凭据的远程地址不得持久化。
- 所有生产代码先有失败测试，再实现最小修复。

- [ ] **Step 4: 实现最小导入器**

收集命令标准输出，规范化仓库根目录和 origin。验证 origin 主机等于
