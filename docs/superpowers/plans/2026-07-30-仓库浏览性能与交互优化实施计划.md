# 仓库浏览性能与交互优化实施计划

> **供代理执行：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans` 逐项实施本计划。每个步骤均使用复选框跟踪。

**目标：** 交付最早提交在上且覆盖全部本地与远程分支的矢量提交画布、正确的树形文件顺序、缓存优先的仓库内容加载，以及可搜索的仓库切换浮层。

**架构：** 核心层负责全部分支分页换算、拓扑泳道、视口投影、文件树前序排列和仓库内容请求协调；应用层只负责 Canvas 绘制、AppKit 鼠标事件桥接和 SwiftUI 浮层展示。仓库内容通过增量结果流先发布缓存，再合并并发刷新结果。

**技术栈：** Swift 6、SwiftUI Canvas、Observation、AppKit `NSViewRepresentable`、Foundation `Process`、自定义轻量测试运行器。

## 全局约束

- 最低平台保持 macOS 14。
- 所有 Git 命令保持只读。
- 提交历史只覆盖 `refs/heads/*` 和 `refs/remotes/*`，不把标签或 stash 当作分支入口。
- 最早提交位于顶部，最新提交位于底部。
- 画布不使用位图快照或 `drawingGroup()`。
- 内存内容缓存有效期固定为 5 分钟，磁盘摘要有效期保持 15 分钟。
- 不把访问令牌写入缓存、日志、测试快照或文档。
- 文档、测试名称和 Git 提交信息均使用中文。

private func oldestFirstWindow(
    total: Int,
    offset: Int,
    limit: Int
) -> (skip: Int, count: Int) {

}

override func scrollWheel(with event: NSEvent) {

        anchor: anchor
    )
