# 传统提交可调分栏与全分支状态实施计划

> **给 Codex：** 使用 `superpowers:executing-plans` 按顺序执行本文。用户明确要求先完成全部生产代码与测试用例，再统一运行测试；因此任务 1–4 只编写代码和测试，不运行构建或测试命令，所有验证集中在任务 5。

**目标：** 把传统提交布局改成可持久化拖动分割线、左侧全量逻辑分支泳道、右侧固定提交信息，并以实线/虚线清晰区分远程已知提交和本地尚未推送提交。

**架构：** 在完整快照后台派生阶段构建逻辑分支投影与发布状态索引；场景只持久化每仓库的分割线宽度；SwiftUI 传统布局用独立的左侧泳道横向视口和固定右侧信息区消费不可变结果。任何拖动和滚动都不重算 Git 拓扑或可达性。

**技术栈：** Swift 6、SwiftUI、AppKit `NSViewRepresentable`、Swift Package Manager、自定义 `GitMateCoreTestsRunner`。

**执行约束：** 保留当前 `feature/全局与仓库页面10-15` 分支；不处理或暂存 `.superpowers/brainstorm/8145-1786163868/`；所有提交信息与报告使用中文；开发阶段不运行测试或构建，最终统一验证两轮。

### 步骤 1：补齐逻辑分支投影测试用例

- 本地 `main` 与 `origin/main` 合并为第零泳道，全部标签保留。

- 输出全部泳道，不使用 4–8 条容量上限，不生成 `otherLocal`/`otherRemote` 槽；
- 保留现有选中、搜索和引用到泳道映射能力；
- 顺序为 `main`、HEAD、其他本地、仅远程、detached/synthetic；
- 给逻辑槽保存全部底层 `branchIDs` 与展示标签。

### 步骤 4：实现一次性可达性索引

```swift

    case remoteKnown
    case localUnpushed

public struct CommitGraphTraditionalPublicationIndex: Sendable {
    public func state(for hash: String) -> CommitGraphTraditionalPublicationState
    public func isDashed(childHash: String) -> Bool
}
```

从完整引用与父边邻接表分别遍历本地和远程 tip，一次性构建哈希集合。浅克隆边界继续由原边界样式控制。

### 步骤 1：增加 AppKit 分割线手柄

实现 10 点透明命中区、1 点可见线、左右调整光标：

- pointer down 记录起点；
- pointer drag 只更新 SwiftUI 本地 `dividerWidth`；
- pointer up 调用一次 `onCommit(width)`；
- double click 恢复默认宽度并提交一次；
- 拖动时吞掉点击，不触发提交节点选择。

### 步骤 2：拆分传统视图的两套横向状态

在 `CommitGraphTraditionalView` 中：

- 删除整层 `horizontalOffset`；
- 增加本地 `dividerWidth` 和 `laneHorizontalOffset`；
- 由场景保存值和窗口宽度解析当前分割位置；
- 只在左侧命中区域消费横向触控板滚动；
- 分支区域从第零泳道开始，分支很多时只滚动左侧；
- 右侧头像、文字、哈希、标签始终固定；
- 继续只生成真实可见头像行并裁剪固定头部。

### 步骤 3：调整 Canvas 绘制坐标

给 `CommitGraphTraditionalCanvas` 传入：

- `laneViewportWidth`；
- `laneHorizontalOffset`；
- `CommitGraphTraditionalPublicationIndex`。

用固定泳道间距计算全量内容坐标，再减左侧偏移；左侧图形在分割线处裁剪。行背景与分隔线铺满，提交信息从分割线右侧统一起算，不再因泳道数量压缩或越界。

### 步骤 4：应用实线/虚线语义

- `.remoteKnown` 节点轮廓和从该子节点发出的全部父边使用实线；
- `.localUnpushed` 使用同色虚线，并在右侧信息显示“未推送”徽标；
- Merge 不再仅因 `kind == .merge` 自动虚线；
- 浅克隆边界保留原警示虚线；
- 额外引用 tip 的连接线同样按 tip 提交状态绘制。

### 步骤 5：更新分支栏与大量分支性能用例

- 分支栏保留全部本地与远程标签，可横向滚动；
