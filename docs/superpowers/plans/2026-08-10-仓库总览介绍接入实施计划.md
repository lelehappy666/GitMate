# 仓库总览与介绍接入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让仓库工作区侧边栏中的“总览”和“介绍”成为可用入口，并复用既有总览与 README 页面、缓存和鉴权能力。

**Architecture:** 在 `RepositoryWorkspaceRoute` 中加入第 12、13 页路由，由应用层 `RepositoryWorkspaceRuntime` 同时持有仓库工具 ViewModel 和内容页面所需的 ViewModel、图片鉴权。仓库工作区内部切换总览、介绍、分支和议题；需要进入文件或提交图时，通过根视图回到既有 `WorkspaceRoute`，避免重复实现页面或数据服务。

**Tech Stack:** Swift 6、SwiftUI、Observation、Swift Package Manager、自定义可执行测试运行器。

## Global Constraints

- 支持 macOS 14 及以上版本。
- 所有界面文案、测试说明和文档使用中文。
- Git 提交信息使用中文。
- 保持白色主色调、高对比文字和现有 1,180 × 760 软件高度规范。
- 总览和介绍必须复用 `RepositoryOverviewView`、`READMEView` 与 `WorkspaceContentService`，不得复制数据加载逻辑。
- Actions、Releases、Packages 继续保持禁用，不在本计划范围内。
- 正式运行时使用钥匙串令牌和共享缓存；预览模式必须使用内存凭据和假数据，禁止访问真实 GitHub。

- [ ] **Step 3: 接入总览与介绍页面**

`RepositoryWorkspaceRootView` 使用完整运行时：

```swift
@Bindable var viewModel: RepositoryWorkspaceViewModel
let overviewViewModel: RepositoryOverviewViewModel
let readmeViewModel: READMEViewModel
let imageAuthorization: READMEImageAuthorization
```

路由内容：

```swift
case .overview:
    RepositoryOverviewView(
        viewModel: overviewViewModel,
        imageAuthorization: imageAuthorization,
        onRoute: handleOverviewRoute,
        onResync: onResync
    )
case .readme:
    READMEView(
        viewModel: readmeViewModel,
        imageAuthorization: imageAuthorization
    )
```

`handleOverviewRoute(_:)` 的精确规则：

```swift
switch route {
case .readme:
    viewModel.navigate(to: .readme)
case .filesAndCommits, .commitGraph:
    onOpenWorkspaceRoute(route)
default:
    onOpenWorkspaceRoute(route)
}
```

`.task(id:)` 只对 `.branches` 至 `.issueLabels` 调用 `loadCurrentRoute()`；`.overview` 与 `.readme` 由其各自 ViewModel 的 `.task` 加载，避免把仓库工具状态错误切成 loading。

`GitMateRootView` 保存 `RepositoryWorkspaceRuntime?`；跨工作区跳转时先写入 `workspaceRoute` 再清空仓库运行时。重新同步时清空运行时并调用 `onboarding.prepareRepositoryResync()`。
