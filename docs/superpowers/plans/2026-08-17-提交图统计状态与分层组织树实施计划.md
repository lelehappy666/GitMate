# 提交图统计、状态与分层组织树实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 修正提交图分支/引用统计与顶部状态显示，统一本地/云端节点和连线语义，并将画布替换为无重叠、无无关穿线、可折叠的自上而下分层组织树。

**架构：** 继续使用完整 Git 快照作为唯一拓扑来源。Core 层在快照派生阶段一次生成逻辑分支、发布状态、组织树坐标、固定端口和稳定走线通道；场景投影只对账分组、手动位置和折叠状态。SwiftUI/Canvas 只消费已派生结果，空间索引负责可见查询与拖动局部更新。

**技术栈：** Swift 6、SwiftUI、AppKit Canvas、Swift Package Manager、现有 `GitMateCoreTestsRunner`、macOS 15+。

## 全局约束

- 所有文档、界面文案和 Git 提交信息使用中文。
- 本地与任意远程的同名分支始终是一个逻辑分支，不因两端已分叉而拆分。
- `origin/HEAD` 等符号引用不计入逻辑分支数和直接引用数。
- 本地与云端一致时连线和节点边框均为实线；任一端独有时均为虚线，仅云端独有节点显示 Cloud 标志。
- 最早提交在上，最新提交在下；父提交必须位于子提交上方。
- 画布默认水平中心间距为 500 px，垂直层级中心间距为 252 px。
- 连线除自己起点和终点外，不得与其他可见卡片相交，并保留至少 28 px 净空。
- Group 仍使用 `origin` + 成员相对坐标；端口 `side`/`offset`、Group、折叠、Region、线型、手动位置和视口不得被刷新破坏。
- 不主动执行 `git fetch`；“云端”以本地已知 `refs/remotes/*` 为准。
- 50,000 提交和 300 分支下，滚动、缩放和每帧绘制不得全量遍历提交或边。

```swift
public func state(for hash: String) -> CommitGraphPublicationState {
    let local = localReachableHashes.contains(hash)
    let remote = remoteReachableHashes.contains(hash)
    switch (local, remote) {
    case (true, true): .synchronized
    case (true, false): .localOnly
    case (false, true): .remoteOnly
    case (false, false): .unclassified
    }
}

public func isDashed(childHash: String) -> Bool {
    let value = state(for: childHash)
    return value == .localOnly || value == .remoteOnly
}

public func showsCloud(hash: String) -> Bool {
    state(for: hash) == .remoteOnly
}
```

```swift
// 1. 使用 oldest-first 拓扑序计算最长路径层级。
depth[child] = max(depth[child, default: 0], depth[parent, default: 0] + 1)

primaryParentByChild[childHash] = commit.parentHashes.first

    .map { subtreeWidth[$0, default: 1] }
    .reduce(0, +))
```
