## 统一视觉规范

- macOS 软件窗口标准高度为 680px。
- 软件主窗口不产生纵向页面滚动。
- 列表、日志、文件、画布和设置内容在面板内部滚动。
- 主色调为白色，使用浅灰层级和少量蓝色强调。
- 主文字使用接近黑色的高对比颜色。
- GitHub 用户身份位置使用用户头像，不使用字母仓库图标代替。
- 危险操作使用分级确认、影响范围和可恢复提示。
