# GitMate 剩余页面批量设计范围

## 已锁定调整

- 完整移除“项目”模块。
- 所有侧边栏不再显示“项目”入口。
- 议题、拉取请求和里程碑不再显示项目关联字段。
- 不设计项目页面、项目设置或项目删除流程。
- 收件箱继续保持移除状态。
- 所有页面采用白色主色调、高对比文字和固定软件窗口高度。

## 统一交付方式

- 每一页生成独立设计稿。
- 额外生成一份连续滚动的完整设计总览。
- 完成后统一检查导航、颜色、文字对比度、用户头像、内部滚动和窗口高度。
- 用户最后统一提出修改意见，不再逐页等待确认。
