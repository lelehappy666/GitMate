先确认产品没有漏掉任何功能域。确认后，我们再逐章进入每个页面的布局、内容、操作和状态。

10 个页面域 · 双层上下文

全局层用于跨账户处理工作；仓库层融合本地 Git 与 GitHub；对象详情可拆分为独立窗口。

覆盖规则

API 支持的操作全部原生化；仅网页支持的低频能力进入安全网页兜底中心；不设计 AI 助手和 AI 内容生成。

覆盖边界说明

原生覆盖REST、GraphQL 和本地 Git 能执行的读取、创建、编辑、删除及管理操作。
网页兜底付款方式、Marketplace 购买、部分身份验证和 GitHub 尚未开放 API 的页面。
明确排除AI 助手、AI 生成内容和内置代码编辑器；Copilot 只保留席位、用量、账单等管理能力。
