按开发生命周期组织页面，用户围绕“下一步做什么”工作；效率突出，但与 GitHub 原有结构差异最大。

目标导向差异化强学习成本较高
我的建议：A「双层上下文」。 GitMate 既要覆盖跨账户工作台，也要融合本地 Git 与仓库远程功能。双层架构能容纳完整 API 能力，同时避免照搬 GitHub 网页造成的本地/远程割裂。
